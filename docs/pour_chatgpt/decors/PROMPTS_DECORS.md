# Tous les décors de CREOS — prompts pour ChatGPT

45 images à refaire : **30 arènes de combat** et **15 fonds d'écran** (échoppe, reliquaire, carte, salles…).
Le but : tout mettre dans le même style peint que ta nouvelle arène du port.

Tout ce qu'il faut joindre est dans le dossier `a_joindre/`. Dépose les images rendues dans `recu/`,
avec le nom indiqué. La taille n'a pas d'importance : je recadre en 1920 × 1080 en les installant.

## Comment faire

1. Ouvre **une conversation ChatGPT par monde** (ou par groupe d'écrans). Au-delà de 4 ou 5 images,
   ChatGPT oublie le style : mieux vaut recommencer une conversation.
2. Premier message : colle le **message de départ** (A pour les arènes, B pour les écrans) avec les
   images à joindre.
3. Ensuite, **un message par décor** : colle la ligne du décor, rien d'autre.
4. Si une image est ratée, réponds avec une des **corrections** de la fin du document.
